# Brain X: Universal Multi-Agent Autonomous Software Company

Brain X provides conversational software company orchestration for @madnessgate44-debug via ChatGPT on Android mobile, featuring universal GitHub administration, the **Tamayim** autonomous browser engine, and a 100% zero-cost multi-provider keyless LLM fallback chain.

---

## 🚀 Core Capabilities
1. **Universal GitHub Authority**:
   - ChatGPT controls GitHub repositories via issues, comment webhooks, PATs, and GitHub Apps.
   - Encrypts and provisions repository/organization secrets via libsodium (`gh secret set`).
   - Authors, modifies, and dispatches GitHub Actions workflows (`.github/workflows/*.yml`).
   - Executes autonomous branch creation, testing, PR publishing, and direct code merges.
2. **Tamayim Autonomous Browser Engine**:
   - Headless Playwright Chromium engine with stealth anti-bot bypass.
   - Live web search and structured DOM/markdown extraction for ChatGPT research.
   - Dual-viewport screenshot verification: Mobile (390x844) and Desktop (1280x800).
   - Interactive DOM automation: element clicking, form fills, and authenticated sessions.
3. **Zero-Cost Multi-Provider LLM Fallback Cascade**:
   - 100% free root models with zero token costs ($0.00).
   - Cascades automatically across FreeLLMPool (local proxy), Pollinations AI, LLM7, OVH Llama-3.3-70B, and OpenRouter Free.
   - Intercepts 429/502/402 errors, honors retryDelay backoffs, and seamlessly auto-switches routes without interrupting company missions.
4. **C1 Security & Isolation Hardening (PR-B)**:
   - Git hook host immunity: `.git` relocated outside the container during execution, neutralizing pre-commit hook tampering.
   - Resilient Gitleaks scanning with `--diff-filter=d` (immune to deletion/rename crashes).
   - Clean POSIX `paste -sd` argument formatting without character corruption.
