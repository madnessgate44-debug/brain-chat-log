Finding 1 [CRITICAL]: Host Runner Escape via Writable .git Volume Mount
- Location: .github/workflows/brain-build.yml, Lines 341-347 & 563-574
- Code:
    "run_args": ["--rm", "--user", f"{os.getuid()}:{os.getgid()}", "-e", "HOME=/tmp", "-v", f"{os.environ['GITHUB_WORKSPACE']}:/workspace"]
    followed by host-side:
    git commit -m "Brain ${COMMAND}: automated candidate"
- Root Cause: GITHUB_WORKSPACE is mounted read-write. An untrusted agent or prompt injection can write to /workspace/.git/hooks/pre-commit or configure core.hooksPath. When step 530 runs `git commit` on the host runner outside Docker, the hook executes on the host VM with access to runner tokens (GH_TOKEN, GH_CONTROL_TOKEN).
- Fix:
    1. Move .git out before launching agent: mv "$GITHUB_WORKSPACE/.git" /tmp/brain-target-git
    2. After agent completion, assert no .git was created by agent and restore:
       [ ! -e "$GITHUB_WORKSPACE/.git" ] || exit 1
       mv /tmp/brain-target-git "$GITHUB_WORKSPACE/.git"
    3. Host git commits run with: git -c core.hooksPath=/dev/null commit --no-verify ...
    4. Read-only audits mount /workspace as :ro.

Finding 2 [MAJOR]: Gitleaks Step Crashes on File Deletions / Renames
- Location: .github/workflows/brain-build.yml, Lines 398-403
- Code:
    git diff --name-only -z | tar --null -T - -cf /tmp/brain-changed-files.tar
    tar -xf /tmp/brain-changed-files.tar -C /tmp/brain-gitleaks-source
- Root Cause: `git diff --name-only -z` includes deleted files. `tar -T -` cannot stat deleted files and exits with code 2. Under `set -e`, this crashes the entire workflow.
- Fix: Filter out deleted files using `--diff-filter=d`:
    git diff --name-only --diff-filter=d -z | tar --null -T - -cf /tmp/brain-changed-files.tar

Finding 3 [MAJOR]: Silent Workflow Termination (Zero Failure Issue Comments)
- Location: .github/workflows/brain-build.yml, Lines 532, 551, 578
- Root Cause: Issue comments are only posted inside the publish step, which only runs if all prior steps succeed. Failures in lease acquisition, credentials, agent, gitleaks, or tests exit silently with no issue update.
- Fix: Add an always()-executed failure step (if: always() && failure() && needs.prepare.outputs.issue_number != '') posting a diagnostic comment with run URL to the issue.

Finding 4 [MAJOR]: tr Expression Mangles File Names and Warnings
- Location: .github/workflows/brain-build.yml, Lines 566-567
- Code:
    files_changed="$(git diff --cached --name-only | head -8 | tr '\\n' ',')"
    warnings="$(grep '^WARN:' /tmp/brain-checks.log | head -2 | tr '\\n' ';' || true)"
- Root Cause: In bash single quotes, `'\\n'` is literal `\` and `n`. `tr` translates every backslash and every letter `n` into commas/semicolons (e.g. `main.py` -> `mai,.py`). Real newlines are untouched, corrupting PR metadata.
- Fix: Use POSIX `paste`:
    files_changed="$(git diff --cached --name-only | head -8 | paste -sd, -)"
    warnings="$(grep '^WARN:' /tmp/brain-checks.log | head -2 | paste -sd';' - || true)"

Finding 5 [MINOR]: git diff --check Aborts Agent Step on Whitespace
- Location: .github/workflows/brain-build.yml, Lines 375, 380
- Root Cause: `git diff --check` exits with status 2 on trailing whitespace. Under `set -e`, this immediately crashes the step before patch creation.
- Fix: Make whitespace non-fatal:
    git diff --check || echo "::warning::Whitespace errors detected in agent changes."

Finding 6 [MINOR]: Trigger Expression Matches Unintended Suffixes
- Location: .github/workflows/brain-build.yml, Lines 45-47, 55-60
- Root Cause: `startsWith` matches `/brain builder`, `/brain retry-now`, spinning up runner VMs unnecessarily.
- Fix: Constrain YAML expressions to exact/whitespace/newline boundaries and update contract tests in sync.

Finding 7 [MINOR]: Misleading Test Reporting When No Tests Exist
- Location: .github/workflows/brain-build.yml, Lines 421-422, 444-449, 574, 578
- Root Cause: If no tests exist, the workflow falls back to compileall/warning with exit 0, but reports `project checks and gitleaks passed`.
- Fix: Export `check_type` from checks step and report fallback status (e.g. `compileall smoke check (no tests found)`).
